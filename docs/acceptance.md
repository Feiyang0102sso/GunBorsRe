# 2026-09-08 游戏验收

## 启动

在项目根目录双击：

| 文件 | 入口 |
|---|---|
| `play-muted.cmd` | 正式游戏，静音，新手账户 |
| `play.cmd` | 正式游戏，开启声音 |
| `play-original-save.cmd` | 原完美存档的独立研究副本，静音 |
| `research.cmd` | 永久研究菜单，静音，原有 1–38 项全部保留，新增 39–46 媒体／原 UI／BOKOR 研究 |

实际程序为 `bin/x64/Release/gun_bros_re.exe`，仍直接读取本项目的原版 BIG。无参数直接启动游戏，研究菜单只由 `--research` 或脚本进入。启动器先切回资源根目录。EXE 全部模式支持 `--mute`，静音照常解码音乐、音效和视频并运行游戏逻辑。`--profile out/my-test.dat` 可指定隔离账户，`--skip-intro` 跳过启动视频。

正常账户写 `userdata/profile.dat`；原存档研究副本写 `userdata/original-profile.dat`。后者首次从 `saves/` 的原记录导入，随后继续自己的进度。源存档始终只读。自动检查使用 `out/` 的独立账户。

## 建议验收顺序

1. 启动静音新手游戏，确认原 Glu 视频、标题页和七项主导航。视频可用空格／点击跳过。检查星球、STORE、BROS、BRO-OPS、REFINERY、OPTIONS、GAMES 及下级页面；星球页可回选已经解锁的旧轮次，未解锁波次保持锁定。
2. WASD 移动、鼠标瞄准、左键射击；1/2 选择已装配双枪，N/M 切枪。G 使用选中道具，F 轮换道具。空格／Esc 暂停，R 重开，C 碰撞叠加；在暂停弹窗点 MAIN MENU 返回菜单。底部枪位与道具、暂停／死亡／重开按钮均可鼠标操作。
3. 确认敌人受击、死亡、拾取物、经验和升级。兄弟跟随、独立射击，死亡后在下一波复活。正常游戏玩家会受伤和死亡。
4. 退出战斗回到菜单，将 Xplodium 免费即时炼化为金币；购买并装配装备，重新进入地图，再关闭程序、启动检查保存结果。
5. 原存档研究入口检查 200 级账户、原双枪和 Infinity 三件盔甲；此入口可直接体验高等级装备。装备页显示选中盔甲的防御、攻击、移动、XP、Xplodium 五项属性；左侧人物预览随实际换装更新。
6. 研究菜单 18 查看盔甲组合、33 试用道具、35 选择废弃战役。战役对话使用空格继续；战役试玩不改正式账户。
7. 主导航 GAMES → BOKOR / HORDE，选择十档 Horde 起始难度；检查计时、连杀、POINTS 和保存的最好成绩。顶部货币入口可进入原目录货币包／双向兑换，确认页明确是本地模拟，不发生真实支付。
8. 开声音启动时确认菜单曲与战斗曲：原 iOS CBGM 使用菜单 `game_0.mp3`，每次进入战斗依序选择 `1.mp3` 至 `6.mp3` 并循环当前曲目，不是每星球固定一首。OPTIONS 的音乐／音效设置分别保存。

## 重复检查

已构建的版本可运行 `./test-muted.ps1 -Configuration Release -Phase Core`，逐项检查核心数据、战斗、菜单、保存和渲染。`Debug` 可替换 `Release`；每项保存命令、退出码和耗时到 `out/validation/`。

`-Phase Campaign` 跑六条战役的移动／战斗烟测，仍不代表完整通关；`-Phase LongRun` 顺序跑四图各 500 波，耗时较长。所有阶段强制静音、意外失败即停止，并比较前后原存档及正式账户 SHA256。已知 PROP 43 必须匹配具体诊断，汇总中保留 `KnownDataIssue`，不标为干净通过。

`-Phase UI` 检查完整媒体解码、视频播放、175 个电影／13 套字体、core 画廊、HUD、菜单以及 BOKOR 首尾难度。报告位于 `out/validation/`。

`-Phase Boundary` 从四图第 499 波分别推进至第 500 波完成，检查最终过波、结束状态及未实现脚本计数。它补充完整长跑，不能替代从第一波开始的 500 波验收。`-ExecutablePath` 可指定独立 QA 构建；各次报告记录实际 EXE。
