## 启动与账户

直接双击 `bin/x64/Release/gun_bros_re.exe` 启动正式 Windows GUI，不弹控制台。资源仍直接读取本项目 `big/`；当前开发构建保存了项目资源根路径，尚未制作独立安装包。

| 入口 | 用途 |
|---|---|
| `play-muted.cmd` | 静音正式游戏，脚本自身会经过命令解释器；验收无控制台请直接启动 EXE |
| `play.cmd` | 开声音正式游戏 |
| `research.cmd` / `gun_bros_research.exe` | 永久研究菜单，保留 1–75 项，独立控制台程序 |
| 窗口系统菜单 → Research tools | 从游戏打开附属研究工具 |
| `play-original-save.cmd` | 从原标准存档建立独立账户副本；不再优先导入 `.perfect` |

正式游戏默认写 `userdata/saves/`。首次从 `saves/` 标准文件名只读导入；没有源目录时按原构造和 BIG 默认装备独立创建。已有本地账户继续自己的进度，源存档不覆盖它。原记录、CRC、padding 和未解释字段保留，写入采用每文件原子替换。

`--profile out/my-test-saves` 指定隔离原格式目录；显式 `.dat` 仅用于保留旧研究，不能作为原存档验收。`--mute` 静音但照常验证资源和运行逻辑，`--skip-intro` 跳过启动视频。Explorer 启动日志位于 `userdata/logs/game-PID.log`。

正式运行不需要研究 EXE，也不链接研究驾驶器；需要研究时才启动伴随工具。旧 `store-template-demo.cmd` 等研究入口继续保留。

## 建议验收顺序

1. 启动正式 EXE。视频播放完立即显示原 Splash 图，不插入加载 CG；资源加载时右下角播放原小人 Sprite。加载完成后 BIG font11 的 `TAP TO CONTINUE` 闪烁，点击任意位置或按 Enter／空格继续。新账户随后选兄弟，再完成移动、射击、免费步枪、切枪和手雷教程；老账户走原签到入口。签到退出时才发奖，重新进入不重复领取。首次标志与教程提示是不同字段。
2. 菜单切换和商店分类应播放原横扫；转场期间不能点穿。进游戏/回菜单出现原加载 CG，图外提示文字读 STR。进入 STORE，检查原商品两行列表、GUNS／ARMOR／POWER UPS、FILTER、商品展开／收起、预览和购买。首列 Invite / Get Free Warbucks 打开原绿色弹窗，X关闭后仍在商店；平台服务尚未接入，点击不会发邀请或奖励。熟练度使用原章节、99%阈值与星动画；升级弹窗使用原六态、价格和NEXT流程。
3. 商店右侧模型由原UI动作、原身体边界和整页投影绘制，原区域不再当小视口裁切。拖动旋转、松手回正；换枪先播放旧枪动作，再由原脚本切槽。大枪的特定姿态遮脸仍需与同武器原版画面核对，未用缩小或额外旋转补丁掩盖。
4. BANK 检查原货币包及双向兑换。商品和金额来自 BIG；内购等待约4秒后本地到账是此前明确授权的离线模拟，不发生真实支付。余额不足走原提示，重复点击不会重复结算。
5. PLAY → STANDARD → 原星图选择星球 → REVOLUTION → WAVE → PLAY。四个生存星球按原引用进入各自一张地图，保留50波×10轮进度。BOKOR／HORDE使用其原关卡和独立高分记录。GAMES对应原PlayHaven服务，离线不再跳到自造BOKOR菜单。
6. WASD移动、鼠标瞄准和左键射击；Q/E使用左右powerup，1进入战斗道具选择器，2切换双枪（含角色动作及按钮按压反馈），Esc/空格暂停。红按钮进入战斗道具选择器，蓝按钮切枪。核对敌人调度、受伤／死亡、击杀和经验。升级、开波、清波、完美奖励按原Movie时长播放，通知结束驱动下一波，播放期间战斗继续；慢动作由原脚本倍率控制。
7. Esc／空格暂停。单机暂停为原六项，帮助原14项；音效、音乐和摇杆停靠写原 `p` 设置文件。SURRENDER进入结算。正式生存移除F/R快捷键；独立Arena等里程碑保留原研究键位，不能据此绕过正常死亡验收。
8. 结算检查原熟练度弹窗、Overview／Casualties、实际击杀模型与分数、BACK倒放。有XPlo进入精炼，零XPlo返回星图。离线使用原零时长炉子：转移、开始、完成、单独领取，随后重启核对余额、库存和进度。
9. OPTIONS检查原列表、帮助、关于、切换兄弟及设置重载。BROS／BRO-OPS按真实离线身份显示原提示；没有有效网络状态时不产生好友或挑战奖励。

## 明确保留的差异

- 尚未逐帧对齐所有原版页面；部分列表惯性、越界回弹、卡片和页面退场、粒子及HUD细节仍缺。模型不裁切和正确投影不等于所有武器姿态已经1:1。
- 战斗选择器恢复15条原目录；14条受支持购买，复活效果未完成时显示不可用且不扣钱。战斗内购买更多→Bank→返回的完整链未接。
- 真实联网、好友、多人匹配／同步、部分活动和联网精炼未实现，不以本地演示伪造联网状态。
- 原存档18类记录可读写，未恢复每个客户端全部业务；未解释字段原样保留。源 `saves/`、BIG和主程序原件始终只读。
- 战斗算法、随机序列和特效仍有待核对项。原旧PC版和未知版本Flow只作补充，不能覆盖当前iOS和BIG证据。
