# stboss 作弊码

用户已确认实现。连续输入 `stboss` 后自动完成当前普通波并进入原 Boss 入场，不需手动清怪或按回车。它是 Windows 宿主作弊功能，不冒充原版作弊码。

## 方案与任务

- [x] 扩展现有 `ch*` 按键识别，支持六字母、忽略自动重复，保留 S 的普通移动。
- [x] 利用 LEVEL variable 5 的原强制 Boss 分支，后台快速推进剩余调度和死亡回调；入场序号变化时立即停止快进。
- [x] 区分地图摆放机关与动态刷怪，保留 Haven 炮台和友军；已有 Boss 时不重复执行。
- [x] 通过 SDL 事件、四地图首波及后续波次验证，并更新 Release。

原依据：`entries/level_template.bt`、`flow_bytecode.bt`；四正式 LEVEL Flow；`CLevel::OnEnemyKilled`（iOS :119306）、`HandleEvent`（:117195）、`CEnemySpawner::UpdateRule`（:146849）。pack2 Flow 原 bin 0x33F6 检查 variable 5，0x3404 将本次概率置 100%。不硬编码 LEVEL 状态号，不清空刷怪器后伪造击杀计数。

仅标准生存使用。教程、Horde、已死亡或已结束关卡、空袭演出中拒绝执行；Boss 正在入场或战斗时保持当前 Boss。快进有模拟时长上限，异常时记录实际状态，不能假报成功。

## 结果

已实现于 CWindow、SurvivalSession::SkipToBoss 和 MapScene 的作弊码分派。地图机关以真实 SpawnMapObject 来源标记，动态刷怪即使有跟踪 objectId 仍可清除，没有按炮台 ID 手写排除表。

输入方式：标准生存场景内切英文输入，依次按 `s t b o s s`，不用回车；相邻字母超过 2.5 秒会沿用已有作弊码超时规则重置。正式前端和独立生存研究入口均支持。暂停菜单中成功使用会收起菜单并进入 Boss 入场。

快进期间临时保护玩家和兄弟，完成后恢复各自无敌开关；清除跳过的弹体和音效，保留最后一帧生成的 Boss 入场效果。击杀回调、经验、关卡计时和临时效果计时仍随原流程推进；Boss 生成后恢复正常速度，入场动画不会被跳过。
