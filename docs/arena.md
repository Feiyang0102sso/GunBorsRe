# Arena 敌人战斗测试

2026-09-07：菜单 **16 — Arena** 已接入通用敌人战斗、双方伤害与玩家生命。
一个空白场地按 ENEMY 目录切换，不需要维护 78 份相同地图。

## 启动与操作

运行 `bin/x64/Release/gun_bros_re.exe`，在控制台菜单输入 `16`。
也可以从项目根目录启动：

```powershell
.\bin\x64\Release\gun_bros_re.exe --arena
.\bin\x64\Release\gun_bros_re.exe --arena 49 --weapon 47
```

编号从 **0** 开始。画面顶部显示包名、资源编号和当前武器；条目 49 是便于验证绿色血条的友方示例。

| 按键 | 操作 |
|---|---|
| 左／右方向键 | 切换敌人模板，清场并放置一个该模板单位；保留武器 |
| X | 在玩家周围追加同种单位；检查场地边界与出生间距，无空位时显示提示 |
| R | 重置双方生命、脚本、弹体、音效和战斗统计；保留武器和无敌开关 |
| G | 切换玩家无敌，**默认开启**；只在 Arena 中使用此含义 |
| WASD、鼠标、左键 | 移动、瞄准、开火 |
| 1–7、N／M | 切换武器分类、类内前后切换，复用现有武器逻辑 |
| 空格 | 暂停／继续，循环音效一起暂停 |
| `.`（句点） | 保持暂停，只推进 **16 毫秒**；按一次走一步 |
| C | 显示实际参与判定的圆形／轮廓碰撞体 |
| Esc | 退出 |

暂停时可以切换模板、换枪、重置和添加单位。死亡后停止移动、射击及换枪，按 R 重新测试。

## 生命、伤害与阵营

玩家初始生命为 **6**：来自原版 `PLAYER_PROGRESS` 的等级 1 记录，等级 0 的零值是占位。
HUD 中 `HP` 是当前／最大生命；`INCOMING` 是累计应受伤害，`LAST` 是最近一次伤害。
默认 `GOD ON` 会记录命中和应受伤害，但不扣血。关闭后正常扣血，生命归零仅结算一次死亡。
换枪不会回血、复活或抹掉伤害统计。

武器使用 BULLET 模板基础伤害与脚本爆炸参数；光束使用脚本配置的伤害周期进行时间缩放。
敌人生命由出生脚本设置。当前测试条件为关卡倍率 1、熟练度 0，不加护甲、暴击和成长增益。
**没有把所有枪统一成一个测试伤害。**

- 红色血条：允许继续检测玩家弹体；最终是否扣血仍由受击脚本决定，例如盾牌可以拒绝正面命中。
- 绿色血条：玩家弹体直接跳过，不能造成伤害；友方类型仍保留自身原版脚本。
- 无脚本条目：显示 `UNUSED - NO SCRIPT`，保留目录位置，不编造 AI。
- `FILTER` 是原版受击过滤字段，`TARGET TYPE` 是选敌类型，两者不是同一个属性。

对敌人造成的伤害先触发受击脚本，再根据脚本接受／忽略和倍率进行结算。
生命归零后播放死亡状态，停止攻击、受击和选敌；脚本移除对象，超时尸体也会清理。
`KILLS` 只用于测试计数，不发放奖励。

## 实现位置

| 文件 | 职责 |
|---|---|
| `gun_bros/EnemyCombat.*`、`CEnemy.*` | 每实例独立脚本变量、目标、行为、计时器、攻击、受击及死亡 |
| `gun_bros/CombatTypes.h`、`CBrother.*` | 通用战斗消息、玩家生命、伤害及敌人原生眩晕 |
| `gun_bros/CBullet.*`、`WeaponEffects.*` | 双方弹体、连续碰撞查询、穿透／反射、爆炸、光束及音效 |
| `runtime/CombatScene.*` | 出生、选敌、阵营过滤、碰撞、动作提交及生命周期 |
| `milestones/Arena.*` | 菜单模式、输入、空场地、血条和可重复检查 |

上表源码路径均相对 `src/gun_bros_re/`。效果和声音按实体归属管理，换枪不会清掉敌方弹体，
移除一个敌人不会停止另一个同模板实例的循环音效。模型缓冲在建立时填入首帧，
进入场景、暂停时换枪或重置都不依赖“先更新一次再能绘制”。

## 可重复验证

```powershell
.\bin\x64\Release\gun_bros_re.exe --arena-check
.\bin\x64\Release\gun_bros_re.exe --weapon-check
.\bin\x64\Release\gun_bros_re.exe --arena 0 --weapon 0 --fire --collisions --advance 600 --screenshot out/arena-collisions.png
.\bin\x64\Release\gun_bros_re.exe --arena 15 --screenshot out/arena-unused-initial.png
```

`--arena-check` 写入 `out/arena-check.csv` 和 `out/arena-weapons.csv`，失败返回非零。
`out/` 是本地验证输出，不提交二进制资源。

本轮结果：

- **78 个 ENEMY 条目**加载、出生及更新检查通过；76 个有脚本，2 个无脚本。
- 无脚本的是目录 **15 / pack1 enemy 15**、**62 / pack6 enemy 6**；前者缩放还为 0。
- 远／近目标、受击、死亡状态更新所执行到的敌人原生调用，未知项 **0**。
- **76 把武器**切换与开火回归通过；其中 73 把有完整开火数据，均通过实际伤害检查，3 把纯展示资源独立标记。
- 固定命中、打空、高速扫掠、友方过滤、多实例独立、连续刷怪、眩晕恢复、玩家无敌／受伤／死亡、换枪保留生命、重置清场通过。
- 光束在 960 毫秒内，以 8／16／32 毫秒步长分别造成约 **115.195** 点伤害，三者一致。
- Release、Debug 均构建通过，两个配置的 Arena 检查均为零失败；普通战斗、友方和缺脚本条目的截图已核对。

目录调查是有限运行覆盖，不代表穷尽每个脚本的所有条件分支。报告中的 `deferred` 位：
1 为 Boss 表现，2 为关卡上下文，4 为奖励。孤立友方没有敌方目标时不射击，不能据此判失败。

## 仍待完成的边界

本轮明确排除：**Boss 特殊机制、手雷造成的眩晕、击杀奖励**。Boss 条目仍可浏览和测试其通用部分，
涉及 Boss／关卡依赖时显示提示；不会借用错误资源强行生成它依赖的关卡对象。
敌人自身脚本发起的眩晕已接入，与尚未做的手雷眩晕分开。

空 Arena 使用直线移动与有限场地边界；障碍物寻路、关卡路径、波次和刷怪器调度仍需接入真实关卡。
相机震动、关卡音乐／目标通知、特殊弹体的完整闪电／带状轨迹表现仍未还原。
本轮不宣称这些表现或 Boss 全流程完成，也不意味着整个 M5 已验收完毕。
