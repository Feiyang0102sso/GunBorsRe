Config commands in game config (Example alienshooter.cfg or zombieshooter2.cfg).

Most of the config commands work in almost all Sigma-Team games.

|||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||

Config Structure:

[Section]
Command=Value or Numeric

|||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||

List of sections and config commands:

[common], [game], [graph], [control], [debug] 

|||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||

Commands:

[common] 
Title=Alien Shooter 							; Game window (Change name)
RegPath=SOFTWARE\Sigma-Team\Alien Shooter 		; Path to registry
DefaultSave=    								; Default Save Game Folder

[graph] 
WindowPositionX= 								; Game Window Position X 
WindowPositionY= 								; Game Window Position Y 
AppAccel= 	 									; ???
Device= 										; Graphics Accelerator (0\1\2\3\4 è ò.ä.)
DefaultScreenX=1024 							; Screen Resolution X
DefaultScreenY=768 								; Screen Resolution Y
DefaultFullScreenMode=1 						; Fullscreen mode (0\1)
DefaultColorBPP=32 								; Color Depth (16\32)
Font=Courier New  								; Fonts
FontSizeX=7 									; Font Size X
FontSizeY=8 									; Font Size Y 
VSync=1 										; VSync (0\1) 
BlackWhite=1 									; Black White Render (0\1)
VertexSoftware=1 								; ???
zmUltraLow=1 									; Very Low Settings for dev (0\1)
SoundHighQuality=1 								; High Quality Sound (0\1)
GraphDetail= 									; Graphics Detail (0 - low, 1 - medium, 2 - high)
TripleBuffer=1 									; ???

[game] 
Resource=Objects.res 							; Path to file objects.res 
ArcadeGame=1 									; ???
DrawPresentation=1 								; Demo Message
StartDialog=1 									; Start Dialog
StartDialogIsFull=1 							; Start Dialog with extra options
StartMap=maps\your_map.map  					; Start map (Path to map)
DebugMode=1 									; Debug Mode (Enable debug hotkeys too) 
Dialogs=text\dialogs.txt 						; Path to file with dialogs
DrawFPS=1 										; Enable FPS Counter
SaveDemo=1 										; Enable Demo record (doesnt work)
DrawDebugInfo=1 								; Enable Debug info on screen
DrawGammaIntersection=1 						; Enable Gamma Intersection for units in debug mode 

[control] 
Left=A  										; Step left
Right=D 										; Step right
Up=W 											; Step forward
Down=S 											; Step back
Next=E  										; Next weapon
Prev=Q  										; Previous weapon
First=LBUTTON 									; Shoot
Second=RBUTTON  								; Go to the cursor
Relative=0 										; ???
 
[debug] 
zLocalLogs=1 									; Save logs in game folder
zLocalSaves=1 									; Save profiles in folder
zNoSysMenu=1 									; Disable sys menu in window mode
zDrawUnitInfo=1 								; Enable debug info for units in debug mode 
zNoBuildToTerrain=1 							; A mode in which there is no embedding when loading a map.

|||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||||

Debug hotkeys (Works only with DebugMode=1):

F2												; Save game
F3 												; Load map, save, demo
Shift+F9 										; Screenshot
F10												; ???
Shift+H 										; Show units hp
Shift+M 										; Show collision 
Shift+P 										; Pause 1
Shift+I 										; Various Debug Info
Shift+O 										; Show collision 2
Shift+G 										; Show unit path
Shift+J 										; Disable shadows 
Shift+L 										; Disable light sources
Shift+N 										; Pause 2
Shift+B 										; Pause 3
