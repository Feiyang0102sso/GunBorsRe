# Gun Bros Re for Windows

`Gun Bros Re` 是一个面向 Windows 的《Gun Bros》非官方重制项目。项目使用 C++17、SDL3 和 OpenGL 重建游戏运行时，并提供游戏本体和资源查看器。

当前项目仅支持 Windows x64。运行游戏需要从合法拥有的 iOS 3.6.0 版本中取得 XGA BIG 资源，不需要 HVGA BIG 资源。

## 作弊码

在游戏窗口中直接连续输入小写字母即可，无须按回车。输入时不要按住 `Shift`、`Ctrl`、`Alt` 或 `Windows` 键；相邻字符的输入间隔不能超过 2.5 秒。作弊码在 Debug 和 Release 版本中均可使用。

### `ch`：角色与进度

| 作弊码 | 效果 | 适用位置 |
| --- | --- | --- |
| `chm` | 增加 500,000 金币和 500 Warbucks | 菜单、战斗 |
| `chplo` | 增加 500 Xplodium | 菜单、战斗 |
| `cht` | 将每日奖励计时推进一天 | 菜单、战斗 |
| `chupdate` | 将挑战日推进一天，更新 BRO-OPS 并保存 | 菜单、战斗 |
| `chxp` | 提升到下一级的起始经验；满级后不再增加 | 菜单、战斗 |
| `chlvmax` | 提升到 BIG 经验表定义的最高等级 | 菜单、战斗 |
| `chw` | 解锁四个正式生存星球的全部波次 | 菜单、战斗 |

`chw` 只修改波次进度，不会赠送完美波奖励，也不会绕过星球本身的等级限制。

### `st`：状态与战斗

| 作弊码 | 效果 | 适用位置 |
| --- | --- | --- |
| `std` | 开启或关闭调试模式 | 菜单、战斗 |
| `stc` | 开启或关闭本地联网菜单适配器 | 菜单、战斗 |
| `stref` | 将正在工作的精炼槽推进一天 | 菜单、战斗 |
| `stlockref` | 解锁或重新锁定可用的精炼槽 | 菜单、战斗 |
| `stboss` | 快进到当前生存关卡的 Boss | 生存战斗 |
| `stk` | 使当前角色进入死亡流程 | 战斗 |

`stboss` 在暂停、救援或任一角色播放道具动画时不可用。`stc` 只启用本地重建的联网菜单，不会连接已经停止服务的官方服务器。

### `bro`：本地队友

| 作弊码 | 效果 | 适用位置 |
| --- | --- | --- |
| `brow` | 让本地 Bot 播放正常换枪动画 | 单人好友、Live |
| `brok` | 杀死本地 Bot | 单人好友、Live |
| `bror` | 复活本地 Bot | 单人好友、Live |
| `bros` | 让本地 Bot 打开持续 10 秒的战斗商店 | Live |
| `brop` | 让本地 Bot 随机使用一个可用道具 | Live |

## 配置文件

游戏首次启动时会在 `GunBrosRe.exe` 所在目录创建 `GunBrosRe.cfg`。启动窗口可以修改常用选项；也可以关闭游戏后直接编辑该文件。

配置键区分大小写。方括号中的段名只用于整理内容，不影响配置键的读取。

| 配置键 | 取值 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Title` | UTF-8 文本 | `GunBroRe` | 游戏窗口标题，不需要引号 |
| `StartDialog` | `0` 或 `1` | `1` | 启动时是否显示设置窗口 |
| `ScreenX` | `1`–`16384` | `1600` | 窗口客户区宽度 |
| `ScreenY` | `1`–`16384` | `1200` | 窗口客户区高度 |
| `SoundVolume` | `0`–`10` | `3` | 背景音乐音量；`0` 为静音，`3` 接近原版音量 |
| `EffectsVolume` | `0`–`10` | `3` | 音效音量；`0` 为静音 |
| `IsConnected` | `0` 或 `1` | `0` | 是否启用本地联网菜单适配器 |
| `DMBotLevel` | `1`、`2`、`3` | `1` | Deathmatch Bot 难度：简单、普通、困难 |
| `control` | `1` 或 `2` | `1` | 操作方式：屏幕鼠标瞄准或右摇杆拖动 |
| `DebugMode` | `0` 或 `1` | `0` | 是否启用调试信息和调试快捷键 |
| `DrawFPS` | `0` 或 `1` | `1` | 是否显示 FPS |

示例：

```ini
[common]
Title=GunBroRe
StartDialog=1
ScreenX=1600
ScreenY=1200

[audio]
SoundVolume=3
EffectsVolume=3

[game]
IsConnected=0
DMBotLevel=1

[control]
control=1

[debug]
DebugMode=0
DrawFPS=1
```

启用 `DebugMode` 后可以使用以下快捷键：

| 快捷键 | 功能 |
| --- | --- |
| `Shift+C` | 显示或隐藏碰撞轮廓 |
| `Shift+I` | 显示或隐藏运行信息 |
| `Shift+M` | 打开地图浏览器 |
| `Shift+T` | 打开菜单教程检查 |

地图浏览器使用方向键选择地图或翻页，按 `Enter` 加载，按 `Esc` 返回。地图预览使用当前存档的副本，不会写回正式进度。

## 构建

### 环境要求

- 64 位 Windows
- Visual Studio，安装“使用 C++ 的桌面开发”工作负载
- MSVC v145 平台工具集
- Windows 10 SDK

SDL3、zlib 等项目依赖已经包含在仓库中，无须另外下载。

### 运行时资源

构建前请确认仓库根目录中存在以下目录：

```text
big/       从 iOS 3.6.0 提取的 XGA BIG 资源
assets/    项目自带的着色器、启动资源、音频和图标
```

项目不需要 HVGA BIG 资源。缺少上述任一目录时，构建会在复制运行时文件的阶段失败。

### 使用构建脚本

在仓库根目录运行：

```bat
"vs2026 build.bat"
```

默认同时构建 Debug 和 Release。也可以只构建一个配置：

```bat
"vs2026 build.bat" Debug
"vs2026 build.bat" Release
```

自动化调用时可使用 `/nopause`，避免脚本等待按键：

```bat
"vs2026 build.bat" Release /nopause
```

构建脚本会自动定位 Visual Studio 和 MSBuild，主要生成以下程序：

| 程序 | 用途 |
| --- | --- |
| `GunBrosRe.exe` | 游戏本体 |
| `GunBrosViewer.exe` | BIG 资源查看与研究工具 |

构建产物位于 `bin/Debug/` 或 `bin/Release/`，构建日志位于 `obj/build-Debug.log` 或 `obj/build-Release.log`。

## 未来计划与常见问题

### 统一引擎？

不会。

各个 Gun Bros 版本使用的 BIG 资源差异很大，不同大版本之间也存在明显的结构变化，例如 Section 31、32、33 和 35。即使 Section 编号相同，资源内部的细节也可能不同。

MvM、Star Blitz、Eternity Warrior 等套皮作品同样存在大量差异。若要由一个引擎兼容这些游戏及 Gun Bros 的所有版本，需要分别适配大量资源格式和运行逻辑，投入与实际收益并不相称，因此不计划实现。

### 多语言配置？

不会。

理论上，原引擎具备多语言支持能力，但目前已知的游戏版本均为单语言版本。不同地区的本地化通常由当地工作室单独制作并发布，并不是在同一个版本中切换语言。

此外，游戏使用的是 `fontbitmap`，并非 TTF 字符库。若要制作中文版，需要逐个处理和补充汉字字形，工作量很大，因此目前不计划增加多语言配置。

### 文档？

尚未完成。目前仍有部分 `.bin` 文件缺少 Binary Template，对应的格式说明和研究文档也需要继续补充，后续会逐步更新。

### 多人联机？

目前不支持真正的多人联机。

当前实现只能开放部分原本强制要求联网的菜单，并提供本地 Bot 对战。原版服务器及其通信协议尚未恢复，目前也没有可行方案真正复活官方多人服务。
